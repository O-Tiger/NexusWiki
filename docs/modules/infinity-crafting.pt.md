# Módulo Infinity Crafting

> ⚠️ **Removido em 2026-08-06.** Esta página descrevia anteriormente um sistema de crafting
> multiblock guiado por YAML (`RecipeManager`, receitas `infinity_table`, gate por
> pesquisa/energia) que foi confirmado como **código morto** — não existe nenhum
> `RecipeManager`, carregador de multiblock, ou código de carregamento de receitas em lugar
> nenhum do NexusPrism; restaram apenas strings de idioma soltas, uma constante do enum
> `GuiType`, e um recurso de exemplo não utilizado em `nexusprism-addon-example`. Nenhum
> sistema desses existe atualmente. Veja
> `NexusATS/docs/planning/PLAN-presplit-core-infra.md` para as notas de design se você
> estiver construindo um sistema de crafting substituto no NexusATS.

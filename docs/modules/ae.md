> network storage system (`NetworkStorage` addon manager: ME Controller/cables/drives/
> terminals/storage cells) that was confirmed to be **dead code** — never wired to any
> listener or command, with zero real callers left in the codebase. No such system currently
> ships in NexusPrism. See `NexusATS/docs/planning/PLAN-nexuscore-addon-systems.md` for the
> design notes if you're building a replacement in NexusATS.
>
> Machine/storage content now belongs entirely to **NexusATS**. See that plugin's own
> documentation going forward.
